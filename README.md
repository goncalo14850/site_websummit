Microsite Web Summit 2026
1. Identificação do Projeto

Desenvolvimento de um microsite sobre a Web Summit 2026, um evento internacional de tecnologia, inovação e empreendedorismo realizado em Lisboa.

2. Tecnologias Utilizadas
HTML5 – Criação e estruturação das páginas.
CSS3 – Design, cores e organização dos elementos.
GitHub – Armazenamento do projeto.
3. Funcionalidades Desenvolvidas

O website contém quatro páginas:

Início: Apresentação do evento.
Programa: Horários, temas e sessões.
Oradores: Fotografias e biografias dos oradores.
Inscrição/Contacto: Formulário com validação HTML5.
